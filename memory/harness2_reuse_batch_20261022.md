**Harness² in one line:** 8 editable files around a frozen model (c1 system prompt, c2 guardrails, c3 memory, c4 tool guidance always-on and hard-capped at 24 KB; c6 skills, c5 subagents, c7 scripts on demand; c8 hook inside the tool loop), refined per task by Propose (k INV + k DOM edits) → Probe (each run once on the same task) → Compose (merge / adopt one / KEEP_BASE) → blind anonymised selection over deliverables → reflect `{cue, lesson, evidence, confidence}` + per-edit verdicts (helped/hurt/no effect/confounded) into a per-domain library. Paper: one step +3.3…+11.5 pts; ablation: skills −5.3, scripts −3.7, prompt group −1.5; worst regressions = the blind selector (−41/−30/−28).
